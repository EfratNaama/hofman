# Dashboard Specification

## KPIs
- Total clients
- New clients this month
- Active vs inactive cases
- Services delivered per month
- Volunteer hours logged

## Charts (Recharts)
- LineChart: monthly activity
- BarChart: service categories
- PieChart: case status

## Firestore Queries
- Count documents
- Group by month
- Filter by status
- Aggregate volunteer hours

## Layout (Tailwind)
- KPI cards in a responsive grid
- Charts in 2-column layout on desktop
- Single column on mobile
